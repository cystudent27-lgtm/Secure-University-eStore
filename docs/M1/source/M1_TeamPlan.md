## 5. Collaboration and Version Control

The team will use Git for version control and maintain the project files in a shared repository.

The team will follow these practices:

- Maintain organized project folders and documentation.
- Use meaningful Git commit messages.
- Review important changes together.
- Keep the requirements, ERD, architecture, STRIDE analysis, and API specification consistent.
- Create a Git tag named `M1` for the submitted milestone version.
